<objective>
Open the producer-side write path for `articles.body` — the first half of the bundled Phase 13
sub-wave (f) that T1-01's INTEGRATED-SUB-WAVE workflow shape brings into this phase.

Implements D-04's narrow shape: add an optional `body` field to the `Item` contract, teach
`put_item`/`get_item` about the already-existing `articles.body` column, and hold InMemoryStore at
parity. Nothing else. Per RESEARCH Pitfall 1, do NOT re-implement the superseded pre-SPEC scheme of
per-adapter HTML sanitization and a fixed character cap — SPEC R7 locks "no size cap (TEXT)",
backstopped by an oversized-transcript test.

Covers the contract and storage half of SPEC R7. The seven adapters that set the field ship in plan
12-08. Roadmap requirement: ADR-003.

Purpose: land the shared contract change once, with parity and the NULL-not-empty-string rule
enforced at the single choke point, so the seven adapter edits in 12-08 are one-line changes with
nothing to get individually wrong.

Output: `Item.body`, a body-aware store write path, and a persistence test suite including the
oversized-body backstop.
